# ULUS CHAGHATAY 1337 — the khan's own share, and four domains carved
# out of it (design: the Ulus Chaghatay proposal; organisation in
# in_game/common/international_organizations/ulus_chaghatay.txt).
#
# Base draws CHG as one tag of 127 locations from Urumqi to Tashkent,
# with the Dughlats' Kashgaria as the only eastern domain beside it.
# That makes the khan far stronger in his own right than any khan of
# the 1330s was — Changshi, the fourth khan in three years, ruled what
# his amirs let him rule — and it leaves the eastern party of the later
# split (Moghulistan) with almost nobody in it.
#
# So the khan keeps the Ili and Zhetysu around Almaliq and Almaty, the
# Talas and the Karatau foothills, and the passes north to the Emil;
# four junior members of the ulus take the rest, by whole provinces:
#
#   FGN  Fergana              akhsikath, andijan, farghana        (16)
#        Seat at Andijan, the town Qaidu and Duwa built to be the
#        valley's capital. The hinge between west and east.
#   CAC  Chach                chach, isbijab, otrar, turkestan    (27)
#        Tashkent, Sayram and the middle Syr Darya down to Otrar and
#        Yasi — Chagatayid mint towns facing the Jochid left wing.
#   ISQ  Issyk-Kul and the Chu  chu, issyk_kul, naryn             (17)
#        Balasagun, the lake basin and the upper Naryn: the summer
#        pastures the Tarikh-i Rashidi later calls the heart of
#        Moghulistan.
#   DZG  Dzungaria            yangjibaliq, gurbantunggut          (10)
#        Urumqi, Manas and the northern slopes of the Tian Shan.
#
#   CHG  keeps                almaliq, ilibalyk, kayalyk, almaty,
#                             kuragharty, talas, akkol, emin,
#                             bortala                              (57)
#
# WHO held which eastern valley in 1337 is thinly attested: the main
# source, Mirza Haydar's Tarikh-i Rashidi, is two centuries later and
# writes from the Dughlat side. The four are therefore named by LAND,
# with random rulers, until the houses (Barin, Kereit, Qangli, Bekchik,
# Choras are the candidates) are researched. Pops are untouched: this
# is ownership only.
#
# RELIGION. Fergana and Chach are Sunni and Hanafi — Marghinan is the
# town of the author of the Hidaya. The two eastern domains keep the
# khan's own tengri: the eastern amirs deposed Tarmashirin in 1334 for
# abandoning the yasa, and Islam reached them only with Tughluq Temür
# in the 1350s. (Flip religion_definition in
# in_game/setup/countries/ulus_chaghatay.txt and the include here if
# they should start Muslim like the Dughlats.)
#
# Templates copied from the comparable base amir tags: JLY/BRL for the
# western pair (eurasian_horde_no_coast_no_pleading, legacy_of_genghis),
# CHG/DGH for the eastern pair (eurasian_horde_no_muslim).
#
# CHG is the base block verbatim with the shrunken territory. Its
# tolerated_cultures list is deliberately NOT repeated: setup is
# additive for those lists and a culture named in both the base block
# and a mod block is billed twice (tools/culture_lists.py header).
#
# Same-tag blocks in a later file override the base 10_countries entry
# (precedent: YEM/ZYD in 115_yemen_overrides.txt). File number 116 so
# the new tags exist before 12_diplomacy and
# 15_international_organizations name them.
# =====================================================================
